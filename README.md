# mi-primer-repo

Repositorio de práctica para aprender el flujo de trabajo con Git y GitHub.

## ¿Qué contiene?

Este repositorio se usa para practicar conceptos básicos como:

- Crear ramas
- Hacer commits
- Abrir Pull Requests

## Cómo empezar

```bash
git clone https://github.com/jdelgadoasesoria-ux/mi-primer-repo.git
cd mi-primer-repo
```
